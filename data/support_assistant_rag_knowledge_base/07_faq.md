# Support Ticket System FAQ
**How do I create a ticket?** Provide a concise title, description, project and relevant impact/reproduction details.
**How do I find a ticket?** Search by identifier or use keywords and project filters.
**Can I change priority?** It depends on role permissions and workflow; provide a reason.
**How do I add an update?** Add a comment and distinguish public comments from internal notes where the application supports both.
**What if the issue returns?** Reopen the existing ticket if it is the same unresolved issue and workflow permits.
**Can AI change status?** Only through an authorized application operation and after required confirmation.
**Is every AI answer correct?** No. The assistant must state uncertainty and escalate when evidence is missing.
