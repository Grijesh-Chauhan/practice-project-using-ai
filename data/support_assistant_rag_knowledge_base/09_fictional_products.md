# Fictional Product Catalogue
All names and features are invented for assessment.
- TaskFlow Basic: ticket creation, comments and basic search.
- TaskFlow Team: team queues, assignment, priority management and project reporting.
- TaskFlow Enterprise: configurable workflows, advanced access controls and audit reporting.
A feature may be unavailable because it is not included in a plan. Project access depends on membership and permissions. Verify current configuration rather than assuming a plan includes a capability.
