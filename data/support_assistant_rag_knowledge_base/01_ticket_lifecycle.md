# Ticket Lifecycle
- Open: newly created and awaiting triage.
- In Progress: assigned and actively investigated.
- Pending Customer: waiting for requester information.
- Resolved: a proposed solution has been provided.
- Closed: resolution has been confirmed or closure policy met.
- Reopened: a resolved issue has returned.
Typical flow: Open → In Progress → Pending Customer (if needed) → In Progress → Resolved → Closed.
Do not mark a ticket resolved merely to improve queue statistics. Reopen the existing ticket when the same issue returns; create a new one for a materially different issue.
